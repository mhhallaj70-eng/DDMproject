# Golden Path / مسیر طلایی

## تعریف
سیستم پاداش مرحلهای برای تشویق کاربران به فعالیت مستمر، مصرف محتوا و خرید اشتراک. مسیری منظم و هدفدار برای دریافت دیکوین و جوایز.

## مشکل
کاربران برای مشارکت بیشتر نیاز به مسیر مشخص و انگیزشی دارند. فقدان این مسیر انگیزه و تعامل را کاهش می‌دهد.

## راهکار
دو مسیر موازی:
- **مسیر عمومی**: برای تمام کاربران، جوایز پایه‌تر
- **مسیر ویژه**: برای اشتراک‌دارها، جوایز بیشتر + امکان تکرار بعد از اتمام

## مکانیکا

### جریان کاربر
1. ورود از صفحه کالب
2. نمایش مسیر با پلههای قفل/باز
3. کسب امتیاز از اکشنهای مختلف
4. باز شدن پلهها و دریافت جوایز
5. اشتراک‌دارها جوایز بیشتر می‌گیرند

### ساختار
- مسیر: چندین پله متوالی (Step 1 تا OVERLOAD)
- هر پله: نیاز به امتیاز مشخص + جایزه متناسب
- فصلی: 1 هفته (شامل League + Battle Pass)

## وضعیت پیاده‌سازی

| فیچر | Status | Priority |
|------|--------|----------|
| نمایش مسیر دوگانه | ✅ فعال | Must |

| ثبت و محاسبه امتیاز | ✅ فعال | Must |
| نمایش جوایز | ✅ فعال | Must |
| مسیر تکراری پس از پایان | ✅ فعال | Could |

**وضعیت کلی**: تمام بخش‌های اصلی پیاده‌شده و روی وب + اپ فعال ✅

## چالشهای فعلی

1. **UI**: نیاز به جذابیت بصری بالاتر برای نوجوانان
2. **Balance**: تعیین جوایز متعادل برای حفظ جذابیت
3. **Integration**: هماهنگی فنی با اکشنهای مختلف
