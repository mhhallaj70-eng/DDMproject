# مجله دیدیمون

## خلاصه
تایم‌لاین ویدیویی پویا برای انتشار محتوای کوتاه، قابل تعامل و دسته‌بندی‌شده در قالب تب‌های موضوعی. شبیه فید ویدیوی کوتاه با امکان لایک، کامنت، اشتراک‌گذاری و مارک‌کردن.

**وضعیت:** فعال روی اندروید — وب هنوز توسعه داده نشده  
**مخاطب:** نوجوان ۱۰ تا ۱۸ سال  
**مالک:** تیم محصول دیدیمون | استفاده‌کننده: تیم محتوا + ادمین

---

## User Flow
1. ورود کاربر به اپ (در صورت تنظیم، ورود مستقیم به مجله)
2. نمایش تب‌های موضوعی (سرگرمی، آموزنده، چالش، ترندها)
3. اسکرول بین ویدیوها — پخش خودکار هر ویدیو در حین نمایش
4. تعامل با هر ویدیو:
   - ❤️ لایک
   - 💬 کامنت (بدون خروج از تایم‌لاین)
   - 🔗 اشتراک‌گذاری
   - 🔖 مارک‌کردن برای بعد
5. مارک‌شده‌ها در پروفایل کاربر قابل مشاهده‌اند

| تنظیم صفحه پیش‌فرض ورود | ✅ Completed | — |
| **نسخه وب** | ❌ Not Started | هنوز توسعه داده نشده |

## Edge Cases

| سناریو | رفتار سیستم |
|--------|-------------|
| عدم اتصال به اینترنت | نمایش پیام خطا + گزینه Reload |
| نداشتن ویدیو در یک تب | پیام «فعلاً محتوایی در این بخش وجود ندارد» |
| پخش همزمان چند ویدیو | فقط ویدیوی در حال نمایش باید play شود |
| کامنت توهین‌آمیز | فیلتر هوشمند یا گزارش توسط کاربران |
| ورود مستقیم به مجله | قابل تنظیم در تنظیمات یا هنگام onboarding |

## الزامات فنی

**فرانت:**
- تایم‌لاین اسکرول‌پذیر با ویدیوهای auto-play
- تب‌های موضوعی با فیلتر محتوا
- نمایش و تعامل با لایک، کامنت، مارک و اشتراک
- تنظیم صفحه ورود پیش‌فرض

**بکاند:**
- API دریافت ویدیوهای کوتاه به‌تفکیک موضوع
- API مارک‌کردن و مدیریت لایک و کامنت
- تنظیم صفحه ورود پیش‌فرض
