# خرید سکه (دیکوین خریداری)

## مسئله
کاربران برای شرکت فعال در گیمیفیکیشن (اسپینر، قرعه کشی، خرید آیتم، ارتقاء تراکنش‌ها) به دیکوین نیاز دارند. راهی ساده، سریع و مطمئن برای خرید سکه مورد نیاز است.

## ارزش
- درآمد مستقیم برای پلتفرم
- کاهر مانع در دسترسی به فیچرهای گیمیفیکیشن
- منبع درآمد مهمی از سیستم‌های نقدی پلتفرم

## جریان کاربر
1. کلیک بر ➕ در کنار سکه موجود
2. ورود به صفحه خرید سکه
3. مشاهده بسته‌های متنوع (قیمت + مقدار)
4. انتخاب بسته
5. ورود به مرحله پرداخت (درگاه)
6. تایید دریافت سکه
7. نمایش دریافت + امکان اشتراک

## وضعیت پیاده‌سازی

| فیچر | وضعیت |
|-----|-------|
| نمایش بسته‌های سکه | ✅ |
| رسیدن خریدتصفیه شامل | ❌ |
| اتصال درگاه پرداخت | ❌ |
| مدیریت بسته‌ها از پنل | ✅ |
| دسترسی از تمام نقاط اپ | ✅ |
| نمایش محدود (تیم خاص) | ❌ |

## بسته‌های سکه
مدول قابل پیکربندی — تنظیم از پنل ادمین

## نیازمندی‌های فنی

### Frontend
- دسترسی صفحه خرید از تمام نقاط
- طراحی بسته‌های قابل تنظیم
- ارتباط با درگاه پرداخت
- نمایش تراکنش (موفق/ناموفق)
- رابط کاربری اشتراک

### Backend
- تعریف و مدیریت بسته‌های سکه (مقدار، قیمت، مدت اعتبار)
- ثبت تراکنش در جدول
- تأیید و ثبت در سیستم
- لاگ امنیتی

### درگاه پرداخت
- ارتباط API
- پشتیبانی از چند درگاه (مستقبل)
- مدیریت خرابی و retry

## چالش‌ها و محدودیت‌ها
- رعایت قوانین بانک مرکزی و تسویات
- خطر بازگردانی یا خرابی تراکنش
- عدم دسترسی به درگاه در ساعات خاص
- وابستگی به سرویس‌دهنده

## موارد حاشیه‌ای (Edge Cases)

| شماره | شرح رفتار انتظاری | راهکار |
|-------|-----------------|---------|
| 1 | پرداخت ناموفق | نمایش پیام خطا + امکان تلاش مجدد |
| 2 | بسته از فروش خارج شد | عدم امکان انتخاب + نمایش "پایان یافت" |
| 3 | تلاش خریدن با کیف پول داخلی | انتقال به کیف پول اشتراک |
| 4 | قطع اتصال بعد از پرداخت | افزایش سکه بعد از ورود مجدد |
| 5 | کلیک بدون اتصال اینترنت | پیام خطا + بازگشت |

## ریسک‌ها و تدابیر پیشگیری
- **خرابی درگاه** → افزودن پشتیبانی چند درگاه
- **تراکنش تکراری/مشبوه** → نمایش تایید نهایی
- **قیمت‌گذاری نامناسب** → تحلیل داده + بهینه‌سازی
